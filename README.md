## Overview
PrepVoice AI is a full-stack web application designed to simulate technical interviews. It analyzes candidate resumes against job descriptions (JD), conducts real-time voice-based mock interviews using adaptive questioning, and tracks performance metrics.

## Core Modules
1. **Resume & JD Alignment:** Extracts skills from uploaded PDF resumes and computes compatibility scores against target job descriptions.
2. **Voice Interview Engine:** Real-time speech-to-text transcription and audio question delivery.
3. **Adaptive Questioning & Evaluation:** Generates contextual follow-up questions and evaluates technical accuracy.
4. **Analytics Dashboard:** Tracks overall ratings, practice duration, and skill-wise performance.

## Tech Stack
- **Frontend:** React, Tailwind CSS (Hosted on Vercel)
- **Backend:** Node.js, Express (Hosted on Render)
- **APIs:** Web Speech API, LLM API Integration

## Local Installation
1. Clone the repository:
   `git clone https://github.com/atul2313023-code/PREPVOICE-AI-INTERVIEW.git`
2. Navigate to the project folders and install dependencies using `npm install`.
3. Configure environment variables in `.env` and start the server with `npm start`.
